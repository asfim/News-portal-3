# এইচ টেক প্রোভিশন আইটি (H Tech Provision IT) — বাংলা নিউজ পোর্টাল

একটি আধুনিক, স্কেলযোগ্য ও উচ্চ-পারফরম্যান্সসম্পন্ন বাংলা অনলাইন সংবাদ পোর্টাল। প্রখ্যাত নিউজ পোর্টাল **প্রথম আলো** (Prothom Alo)-এর সমকক্ষ রেসপনসিভ গ্রিড, এডিটোরিয়াল ডিজাইন ভাষা ও ব্যবহারকারী অভিজ্ঞতার আলোকে **H Tech Provision IT**-এর ব্র্যান্ডিং ও নিজস্ব কাঠামোর ওপর নির্মিত।

## ১. প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১.১ পাবলিক ফ্রন্টএন্ড (Public Blade Frontend)
- **আইডেন্টিকাল ডিজাইন ও গ্রিড লেআউট**: প্রচ্ছদে ৩-কলাম বিশিষ্ট লিড হিরো গ্রিড, আলোচিত বিষয়াবলি (`#ট্যাগ` স্ট্রিপ), ভিডিও ক্যারোজেল, আপনার জন্য (পারসোনালাইজড রেকমেন্ডেশন), এবং ট্যাবভিত্তিক সর্বশেষ ও সর্বাধিক পঠিত সংবাদ (১–৬ সংখ্যায়ন)।
- **ক্যাটাগরি ভিত্তিক সেকশনসমূহ**: বাংলাদেশ (বিভাগ ও জেলাভিত্তিক ফিল্টারিং ড্রপডাউন), খেলা, মতামত ও সম্পাদকীয়, বাণিজ্য, বিনোদন, জীবনযাপন এবং তথ্যপ্রযুক্তি।
- **হেডার ও নেভিগেশন**: ৩টি শীর্ষ হেডলাইন সম্বলিত ড্রয়ার স্ট্রিপ, লাইভ বাংলা ক্যালেন্ডার ও সময় (`শনিবার, ০৯ নভেম্বর ২০২৬`), মাল্টি-লেভেল ড্রপডাউন ক্যাটাগরি মেনু, স্লাইড-আউট মোবাইল ড্রয়ার এবং ইনস্ট্যান্ট সার্চ ফিল্টার।
- **নিউজ ডিটেইল পেজ (Single Article)**: কিকার, মূল শিরোনাম, উপশিরোনাম, মাল্টিপল লেখক প্রোফাইল, প্রকাশ ও আপডেটের বাংলা সময় (`bn_time_ago()`), সোশ্যাল শেয়ারিং (ফেসবুক, এক্স, হোয়াটসঅ্যাপ), কভার ফটো/ভিডিও প্লেয়ার, ক্যাপশন, ক্রেডিট এবং রিলেটেড স্টোরিজ গ্রিড।
- **পাঠক এনগেজমেন্ট ও ইন্টারঅ্যাকশন**: পাঠক রেজিস্ট্রেশন, লগইন, সংবাদ বুকমার্ক/সংরক্ষণ এবং মডারেটেড প্লেইন-টেক্সট মন্তব্য ব্যবস্থা।
- **এসইও ও স্ট্রাকচার্ড ডেটা**: ক্যানোনিক্যাল ৩০১ পার্মানেন্ট রিডাইরেক্ট (Public ID + Slug), Open Graph, Twitter Cards, `NewsArticle` এবং `NewsMediaOrganization` JSON-LD স্কিমা।
- **ফিডস ও সাইটম্যাপ**: স্বয়ংক্রিয় আরএসএস ২.০ ফিড (`/rss`), সার্চ ইঞ্জিন এক্সএমএল সাইটম্যাপ (`/sitemap.xml`) এবং `robots.txt`।

### ১.২ সম্পাদকীয় সিএমএস ও অ্যাডমিন প্যানেল (Editorial CMS)
- **রোলে-ভিত্তিক অনুমতি (RBAC)**: সুপার অ্যাডমিন, এডিটর, রিপোর্টার ও রিডার রোল সমন্বিত পলিসি সিকিউরিটি।
- **সম্পাদকীয় লাইফসাইকেল**: `draft` ➔ `review_pending` ➔ `approved` ➔ `scheduled` / `published` ➔ `archived` / `withdrawn`।
- **অপটিমিস্টিক কনকারেন্সি কন্ট্রোল (`lock_version`)**: একই সময়ে একাধিক এডিটর একই সংবাদ এডিট করার সময় ডেটা ওভাররাইট প্রতিরোধ।
- **রিভিশন ও পাবলিক কারেকশন হিস্ট্রি**: প্রতিবার প্রকাশ বা সম্পাদনায় স্বয়ংক্রিয় স্ন্যাপশট সংরক্ষণ (`news_revisions`) এবং স্ট্যাটাস ট্র্যাকিং (`news_status_histories`)।
- **শিডিউলড পাবলিশিং ও ডিউরেবল আউটবক্স**: নির্দিষ্ট তারিখে স্বয়ংক্রিয় প্রকাশনা কমান্ড (`php artisan news:publish-scheduled`) এবং আউটবক্স ইভেন্ট লগ (`publication_events`)।
- **ট্যাক্সোনমি ও কনটেন্ট ম্যানেজমেন্ট**: ক্যাটাগরি, টপিক ট্যাগ, বিভাগ/জেলা/উপজেলা লোকেশন, লেখক প্রোফাইল, মন্তব্য মডারেশন এবং মিডিয়া লাইব্রেরি।
- **বিজ্ঞাপন ও স্পনসর স্লট**: হেডার লিডারবোর্ড, হোমপেজ হিরো রেক্ট্যাঙ্গেল, স্পোর্টস স্পনসর এবং আর্টিকেল ইন-বডি অ্যাড স্লট।

## ৩. লোকাল ডেভেলপমেন্ট সেটআপ (Local Setup on XAMPP)

### ৩.১ পূর্বশর্ত (Prerequisites)
- XAMPP (Apache + MySQL/MariaDB) চালু থাকতে হবে
- PHP 8.3+ (এক্সটেনশন: `pdo_mysql`, `mbstring`, `fileinfo`, `gd`, `openssl`)
- Composer ২.x

### ৩.২ ইনস্টলেশন ধাপসমূহ

১. রিপোজিটরিটি XAMPP-এর `htdocs` ডিরেক্টরিতে রাখুন:
```bash
cd "c:\xampp\htdocs\news portal3"
```

২. ডিপেনডেন্সি ইনস্টল করুন:
```bash
composer install
```

৩. পরিবেশ কনফিগারেশন (`.env`):
```ini
APP_NAME="H Tech Provision IT News"
APP_ENV=local
APP_KEY=base64:...
APP_DEBUG=true
APP_TIMEZONE=Asia/Dhaka
APP_URL=http://localhost/news%20portal3/public

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=news_portal3
DB_USERNAME=root
DB_PASSWORD=
```

৪. ডাটাবেজ মাইগ্রেশন ও সিডার চালান:
```bash
php artisan migrate --seed
```

৫. স্টোরেজ লিংক তৈরি করুন:
```bash
php artisan storage:link
```

## ৬. ব্যাকগ্রাউন্ড শিডিউলার ও ক্রন (Background Scheduler)

নির্দিষ্ট সময়ে শিডিউল করা সংবাদ স্বয়ংক্রিয়ভাবে প্রকাশ করার জন্য প্রতি মিনিটে লারাভেল শিডিউলার চালু রাখতে হবে:

### লোকাল মেশিনে শিডিউলার পরীক্ষা:
```bash
php artisan schedule:work
```

### সার্ভার ক্রনট্যাব (cPanel / Linux Crontab):
```bash
* * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```

ম্যানেজমেন্ট কমান্ড সরাসরি রান করার নিয়ম:
```bash
php artisan news:publish-scheduled
```

## ৮. প্রোডাকশন ডেপ্লয়মেন্ট নির্দেশিকা (Production Deployment)

### ৮.১ cPanel শেয়ার্ড হোস্টিং
1. পাবলিক রুট ডিরেক্টরি অবশ্যই `public_html` অথবা সাবডোমেইনের ক্ষেত্রে `/public` ফোল্ডারে পয়েন্ট করুন।
2. `.env` ফাইলে প্রোডাকশন কনফিগারেশন সেট করুন:
   ```ini
   APP_ENV=production
   APP_DEBUG=false
   APP_URL=https://news.htechprovision.com
   ```
3. ক্যাশ অপটিমাইজেশন কমান্ড রান করুন:
   ```bash
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache
   ```
4. cPanel Cron Jobs মেনুতে গিয়ে প্রতি ১ মিনিটে `php artisan schedule:run` ক্রন যুক্ত করুন।

### ৮.২ ভিপিএস (Ubuntu / Nginx / Apache)
1. Nginx `root` ডিরেক্টরি দিন `/path/to/project/public`।
2. ফোল্ডার পারমিশন নিশ্চিত করুন:
   ```bash
   sudo chown -R www-data:www-data storage bootstrap/cache
   sudo chmod -R 775 storage bootstrap/cache
   ```
3. সিস্টেমড (Systemd) অথবা সুপারভাইজার (Supervisor) দিয়ে ব্যাকগ্রাউন্ড কিউ ওয়ার্কার সক্রিয় করুন।
